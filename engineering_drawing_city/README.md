# Engineering Drawing City

A comprehensive Flutter application for online teaching and learning of technical drawing, designed for students and educators in technical fields.

## Project Overview

This application serves as a digital platform for engineering drawing education, offering features for both instructors and students. It provides tools for lesson management, student progress tracking, assignment submission, and secure authentication.

## Features

### For Students
- **Dashboard**: Track enrolled courses, view progress, and access recent activities.
- **Course Management**: Enroll in courses and manage subscriptions.
- **Progress Tracking**: Monitor completion status, scores, and performance metrics.
- **User Profile**: Manage personal information, view credentials, and change passwords.

### For Instructors (Admin)
- **User Management**: View and manage all registered users (students and other instructors).
- **Course Management**: Create, edit, and delete courses.
- **Lesson Management**: Structure courses into modules and lessons.
- **Assignment Management**: Define assignments, set due dates, and manage submissions.
- **Role Management**: Assign specific roles to users (e.g., Senior Instructor).

### General Features
- **Authentication**: Secure login system with email and password.
- **Admin Authentication**: Dedicated login for administrators with elevated privileges.
- **Role-Based Access Control**: Different functionalities based on user roles.
- **Modern UI**: Clean, responsive interface built with Flutter.
- **Responsive Design**: Optimized for various screen sizes.
- **Error Handling**: Comprehensive error handling and user feedback.

## Getting Started

### Prerequisites
- Flutter SDK (>= 3.0.0)
- Dart SDK (>= 2.17.0)
- An IDE with Flutter support (e.g., VS Code, Android Studio)

### Installation

1. **Clone the repository**:
```bash
git clone <repository-url>
cd engineering_drawing_city
```

2. **Install dependencies**:
```bash
flutter pub get
```

### Running the Application

1. **Start the Flutter application**:
```bash
flutter run
```
